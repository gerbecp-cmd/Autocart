AUTOCART FOR WINDOWS / PC
=========================

1. Double-click Start-AutoCart-PC.bat.
2. AutoCart opens in your default browser at a localhost address.
3. Built-in recipes work immediately, even without the cloud AI service.
4. In Edge or Chrome, use the browser's "Install app" / "Install this site as an app" option to pin AutoCart like a normal desktop app.
5. When the AutoCart AI Worker is deployed, paste its URL under "AI & connection" once. The PC client will remember it.

Keep the small AutoCart Server PowerShell window open while using the local PC version. Closing it stops the local app until you run Start-AutoCart-PC.bat again.
